# Basics
## Introduction
### What Are the Basics in Javascript?
The basics in Javascript refer to the fundamental concepts, syntax, and principles that form the building blocks of the language. It encompasses variables, data types, operators, control structures, functions, and other essential elements necessary for writing effective and efficient Javascript code. Understanding the basics is crucial for any Javascript student, as it provides a solid foundation for more advanced concepts and real-world applications.

### Why This Matters for Javascript Students
Mastering the basics is essential for javascript students as it enables them to write clean, readable, and well-structured code. It also facilitates the development of problem-solving skills, understanding of the language's nuances, and the ability to work with various js libraries and frameworks. Recognizing the importance of basic understanding in coding practices, organizations are consistently seeking developers with solid foundational skills.

## Key Concepts
### Variables
#### Definition
In Javascript, a variable is a name given to a location in memory where a value can be stored. Variables are used to store and manipulate data.

#### Example
```javascript
let name = 'John'; // declare and assign a string to a variable named 'name'
console.log(name); // outputs 'John' to the console
```

### Datatypes
#### Definition
Datatypes in Javascript define the type of data that a variable can hold. The primary datatypes are number, string, boolean, null, undefined, object, and array.

#### Example
```javascript
let num = 5; // number datatype
let str = 'Hello, World!'; // string datatype
let bool = true; // boolean datatype
console.log(typeof num); // outputs 'number'
console.log(typeof str); // outputs 'string'
console.log(typeof bool); // outputs 'boolean'
```

### Operators
#### Definition
Operators in Javascript are used to perform operations on variables and values. They can be categorized into arithmetic, assignment, comparison, logical, and others.

#### Example
```javascript
let a = 5;
let b = 3;
let result = a + b; // addition operator
console.log(result); // outputs 8
let sum = a++; // increment assignment operator
console.log(sum); // outputs 6
```

### Control Structures
#### Definition
Control structures in Javascript dictate the flow of the code execution. They include if/else statements, switch statements, loops (for, while, do...while), and conditional statements.

#### Example
```javascript
let age = 25;
if (age >= 18) {
  console.log('You are an adult');
} else {
  console.log('You are not an adult');
}
```

### Functions
#### Definition
A function in Javascript is a block of reusable code that can be executed when it is called. It takes arguments, performs operations, and can return a value.

#### Example
```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}
greet('John'); // outputs 'Hello, John!'
```
